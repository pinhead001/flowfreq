# Nationwide smoke run

Run date: 2026-11-03. One catalog gage per jurisdiction (longest record, reference class first, else unregulated); a Bulletin 17C fit with station skew at the gage, and a regression estimate (NSS snapshot allowed) at the gage coordinates. Q1% is the 1% AEP flow in cfs. Generated by `tools/nationwide_smoke.py`.

## Known gaps

- DC, VI, GU, MP and AS have no regression-equation library, so their ungaged estimates are expected to fail with `EquationsUnavailable`.
- StreamStats does not delineate in the territories and only partly in AK and HI, so those ungaged estimates may fail at delineation.
- StreamStats' snap service has no stream grid for FL, MI and NE (HTTP 404, `RegionNotDelineatedError`), so no point there can be delineated through its API.
- A state with no unregulated catalog gage has no row to fit; it is reported as such.

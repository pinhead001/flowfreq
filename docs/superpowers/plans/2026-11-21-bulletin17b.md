# Bulletin 17B Procedure Implementation Plan

**Status:** Implemented 2026-11-24.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `Bulletin17B` class and a `b17b_ffa` report section, computed only on request, that run the superseded Bulletin 17B procedure on the same peaks as flowfreq's Bulletin 17C analysis so a report can show what the change in procedure did.

**Architecture:** New module `flowfreq/bulletin17b.py` holds B17B's formulas as pure functions plus the `Bulletin17B` class that applies them in the Appendix 12 flow-chart order. New module `flowfreq/reporting/b17b.py` builds the `b17b_ffa` section on top of it; `reporting/comparison.py` accepts it as an estimate and draws a curve plot only when one is present. `Bulletin17C` (including `method=MOM`) is not touched.

**Tech Stack:** Python 3.11-3.14, numpy, scipy (`scipy.stats.t`, `scipy.special.ndtri`), pandas, matplotlib; `flowfreq.core.kfactor` (exact Pearson III K); pytest.

**Spec:** `docs/superpowers/specs/2026-11-21-bulletin17b-design.md` (approved 2026-11-21). Read it first; this plan argues from it.

## Global Constraints

- B17B is computed and reported **only when requested**: nothing in `gaged_ffa`, `run_ffa`, `Bulletin17C`, the CLI, the chat tools, or a `comparison` without a `b17b_ffa` estimate may compute or show a B17B number.
- `Bulletin17C`, `MethodOfMoments` and every existing report's output are unchanged.
- Every table, caption and section title showing a B17B number says "Bulletin 17B (superseded)".
- No silent fallback: B17B refusals raise `Bulletin17BError` (a `ValueError`) with the reason.
- Python 3.11 syntax (no nested same-quote f-strings); type hints everywhere; NumPy docstrings on public API; `logging`, never `print`; black/isort/mypy clean (`make check`).
- Base-10 logs. Default generalized-skew MSE `0.302`. Confidence limits two-sided 90 percent by default, z = `ndtri(0.95)` (1.64485) each side, systematic record length.
- Tests are offline. Run pytest with `PYTHONSAFEPATH=1` (CLAUDE.md). The 2 known local-only gfortran failures (`test_reproduces_emafitpr_as_g_mse[big_sandy_03606500]`, `test_live_call_matches_the_golden_file`) are not regressions.

## Review Focus

1. **A record with no low outliers, no zeros and no historic period must take the plain path** with no conditional adjustment (`P̃ = 1`); Example 1 pins it, but a reviewer should check no branch applies `P̃ = N/n` when L = 0 (Task 3 test `test_plain_record_has_no_conditional_adjustment`).
2. **A user `low_outlier_threshold` above the median** truncates more than 25 percent and must refuse, not fit (Task 5 test `test_user_threshold_truncating_too_much_refuses`).
3. **Unsorted water years and duplicated years** in the input: sort by year; a duplicated year refuses (Task 3 test `test_duplicate_year_refuses`).
4. **All peaks equal (S = 0)** gives no skew: refuse with the reason rather than divide by zero (Task 3 test `test_constant_record_refuses`).
5. **A `b17b_ffa` estimate whose AEPs differ from the B17C side's** (B17B's default list lacks 0.995/0.667): the comparison must still match common AEPs through `flowfreq.aep` (Task 8 test `test_comparison_matches_aeps_with_b17c`).

### Task 5: Low outliers, zero years and the conditional-probability adjustment (Examples 3 and 4)

**Files:**
- Modify: `flowfreq/bulletin17b.py`
- Test: `tests/test_bulletin17b_conditional.py`

**Interfaces:**
- Consumes: `Bulletin17B`, `synthetic_statistics`.
- Produces: `Bulletin17BResults.conditional` filled.
- Rules: truncated = zeros + `below_base_years` + low outliers (+ peaks below a user `low_outlier_threshold`, which replaces the eq. 8a threshold). Refuse when truncated / `n_years` > 0.25. P̃ = N/n (eq. 5-1a), or (H - WL)/H with a historic adjustment (5-1b). The adjusted curve at P = 0.01, 0.10, 0.50 is evaluated directly: `Q_P = 10 ** (mean_c + kfactor(skew_c, P / P̃) * std_c)` (exact; the bulletin read these graphically). Synthetic statistics by Task 2; eq. 6 at `n_years` with `skew_s` (H if historic). Hand mode rounds the conditional skew to a tenth before evaluating the conditional curve, passes `k_skew=round(skew_s, 1)` to `synthetic_statistics`, and rounds the weighted skew to a tenth.
